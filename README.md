NewAgricoApp is a web application designed to help you manage your farm or crops with ease.
By simply identifying your area on the interactive map, you can access:
-Normalized Difference Vegetation Index (NDVI)
-Ratio Vegetation Index (RVI)
-Normalized Difference Infrared Index (NDII)
In addition, the app provides AI-driven recommendations on how to handle your crop conditions and alerts you to any detected anomalies.
Technologies used : VueJS, Laravel, Python, Leaflet, GEE, TailwindCSS, MySQL.
